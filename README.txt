AMEZA STORE - Shopify install (Online Store 2.0 / Dawn)
1. Themes > Duplicate your theme (backup) > Edit code on the COPY
2. Assets: assets/ folder ki SAARI files upload (css, js, logo, bottle, ing-*.svg)
3. Sections: har .liquid file ke naam se naya section banayein aur code paste karein (perfume-scroll + 10 am-*.liquid)
4. Templates: templates/index.json ka code home page template mein paste karein (ya Customizer mein sections manually add karein)
5. Customizer: Products rails mein apni collection select karein. WhatsApp number AM Extras mein daalein. Discount code Shopify Admin > Discounts mein banayein (AMEZA15).
6. Announcement bar ko header ke upar chahiye to Customizer mein usay sabse upar rakhein.
Product cards ke liye inventory tracking on rakhein taake "Only X left" dikhe.
